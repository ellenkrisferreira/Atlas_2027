O projeto

Aprender também é viajar

O Atlas une uma enciclopédia de países, um guia educativo e um espaço para registrar descobertas. A gamificação será desenvolvida em etapas futuras.

Como este protótipo funciona

Esta primeira versão usa somente HTML e CSS. Os links entre páginas funcionam, o conteúdo pode ser lido offline e o layout se adapta a telas menores.

Login, progresso automático, XP calculado, checklists interativos, busca dinâmica, mapas interativos, banco de dados e sincronização ainda não estão ativos. Eles estão previstos para etapas futuras.

Dica: abra o arquivo README.md que acompanha o projeto para aprender a salvar a pasta no computador, abrir o site e criar novos países.
